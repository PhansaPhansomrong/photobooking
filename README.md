## 📋 เกี่ยวกับระบบ

PhotoQ คือระบบจองคิวถ่ายรูปออนไลน์ของโรงพยาบาลวังน้ำเย็น พัฒนาขึ้นเพื่ออำนวยความสะดวกให้เจ้าหน้าที่สามารถจองคิวถ่ายรูปกับช่างภาพของโรงพยาบาลได้ทุกที่ทุกเวลา

---

## ✨ ฟีเจอร์หลัก

- 📅 **จองคิวออนไลน์** — เลือกวัน เวลา สถานที่ และประเภทการถ่ายรูปได้สะดวก
- 📊 **Dashboard ช่างภาพ** — ดูปฏิทินและรายการจองทั้งหมดในหน้าเดียว
- 📈 **กราฟสถิติ** — ติดตามรายการจองรายเดือนและประเภทการถ่ายรูป
- 👥 **ระบบผู้ใช้** — แยก role ระหว่างเจ้าหน้าที่และช่างภาพ
- 🎨 **เลือก Avatar** — ปรับแต่ง Avatar ด้วย Emoji หรือการ์ตูน
- 📄 **ดาวน์โหลด PDF** — พิมพ์ใบจองได้ทันที
- 🌙 **Dark / Light Mode** — เปลี่ยนธีมได้ตามต้องการ

---

## 🏥 สำหรับเจ้าหน้าที่โรงพยาบาลวังน้ำเย็น

1. เปิดเว็บไซต์ที่ลิงก์ด้านบน
2. กด **"สมัครบัญชีใหม่"** เพื่อสร้างบัญชีครั้งแรก
3. เลือกกลุ่มงานและตั้ง Username / Password
4. เข้าสู่ระบบแล้วจองคิวได้เลย
