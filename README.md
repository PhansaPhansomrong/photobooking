# PhotoQ — ระบบจองคิวถ่ายรูป โรงพยาบาลวังน้ำเย็น

## วิธีใช้งาน

เปิดหน้าเว็บที่ GitHub Pages URL ได้เลย

## การตั้งค่า

ถ้าต้องการเปลี่ยน Apps Script URL ให้แก้ไขในไฟล์ `index.html`  
ค้นหา `APPS_SCRIPT_URL` แล้วเปลี่ยน URL ให้ตรงกับ deployment ของคุณ

## ไฟล์

- `index.html` — หน้าเว็บหลัก
- `Code.gs` — Google Apps Script (API backend)

## GitHub Pages

1. Push ไฟล์ขึ้น GitHub repository
2. Settings → Pages → Branch: main → Save
3. เปิด URL ที่ได้มาได้เลย
